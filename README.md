# 🛡️ Paisa Shield — Financial Confidence for Everyone

A full-stack, multilingual, accessible financial literacy and money-management web application designed for **Students, Households, Farmers, and Rural Communities**.

## 🌐 Live Deployment
- **Frontend (Vercel):** https://paisa-shield.vercel.app
- **Backend API (Render):** https://paisa-shield.onrender.com/api

---

## ✨ Key Features
- **4 Role-Based Workspaces:** Tailored financial dashboards, categories, and goal trackers for Students (`/login/student`), Households (`/login/household`), Farmers (`/login/farmer`), and Rural SHG Communities (`/login/community`).
- **5 Indian Languages & Hands-Free Voice AI (`Alt + V`):** Continuous voice recognition and text-to-speech across **English, ಕನ್ನಡ (Kannada), हिन्दी (Hindi), தமிழ் (Tamil), and తెలుగు (Telugu)** powered by Gemini AI.
- **Gemini Multimodal Receipt OCR:** Upload receipt photos to extract merchant names, amounts, and categories automatically before saving to the ledger.
- **Interactive 3D Financial Breakdown & Smart Jar Splitter:** Real-time 3D expense/income visualization and automatic percentage-based allocation for irregular harvests, stipends, or payouts.
- **Verified Bill Checkout & Scam SMS Shield:** Server-verified payment status handling (pending/failed payments never corrupt ledgers) plus a pre-payment social-engineering scam analyzer and UPI safety quizzes.
- **Offline Rural Sync & Cash-Flow Readiness Passport:** Local offline transaction queuing and self-recorded seasonal financial discipline summaries.

---

## 🛠️ Tech Stack
- **Frontend:** React, Vite, Three.js (`@react-three/fiber`, `@react-three/drei`), Framer Motion, Lucide Icons
- **Backend:** Node.js, Express, JWT Authentication, Multer
- **Database:** Supabase (PostgreSQL)
- **AI & Payments:** Google Gemini API, Razorpay Sandbox Checkout
